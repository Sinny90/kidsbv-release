# kidsbv 发布仓库

本仓库仅用于存放 **kidsbv**（基于 BV 二次修改的个人自用儿童模式版）的自动构建 APK，
供 App 内「关于 → 检查更新」匿名读取。

- 源码仓库（私有）：https://github.com/Sinny90/kidsbv
- 应用包名：`dev.aaa1115910.bv`（固定不变，避免覆盖安装失效）
- 应用显示名：`kidsbv`

## Releases

最新版固定在 `latest` 这个 Tag 下，由 CI（kidsbv 源码仓库的 GitHub Actions）自动发布。
请勿手动删除 `latest` Release，否则 App 内检查更新会暂时取不到版本。

> 本仓库为自用分发渠道，**不对外公开传播安装包**。
